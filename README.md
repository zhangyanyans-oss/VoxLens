# 流式语音识别与同传悬浮面板

基于 **火山引擎流式语音识别 + DeepSeek 翻译 + 百度多音色 TTS** 的桌面实时转写翻译工具。

程序持续采集电脑播放的音频，显示英文原文和中文译文，并可按不同说话人使用不同音色播报。默认打开桌面悬浮面板，也支持原命令行模式。

## 主要功能

- 火山引擎双向流式识别，边说边显示暂存文字。
- 说话人分离，面板按“说话人 1、说话人 2、说话人 3”显示并分配颜色。
- 英文与对应中文译文成组显示，译文不会追加到其他说话人的段落后面。
- DeepSeek 将英文翻译成自然中文。
- 百度 TTS 多音色合成与按顺序播放。
- 翻译和 TTS 默认两个工作线程并行处理，译文及播放仍保持原文顺序。
- 悬浮面板置顶、隐藏、恢复和清空对话。
- 隐藏面板后，后台继续识别、翻译和播报。
- 停止时发送尾部音频并等待最后结果。
- 支持 `.env` 配置，无需把密钥写进源代码。

## 运行环境

建议使用：

- Windows 10／11。
- Python 3.10 或更高版本。
- VB-CABLE 等虚拟声卡；如果直接识别麦克风，也可以使用系统默认输入设备。

推荐在虚拟环境下。

Python 依赖：

```bash
pip install "requests>=2.31" "websockets>=14" "pyaudio>=0.2.14"
```

界面使用 Python 自带的 Tkinter，不需要安装额外的界面库。

## 配置密钥

在程序同目录新建 `.env` 文件，内容如下：

```dotenv
VOLC_APP_ID=
VOLC_ACCESS_KEY=
DEEPSEEK_API_KEY=
BAIDU_TTS_API_KEY=
BAIDU_TTS_SECRET_KEY=
```

等号右侧填写自己的真实凭证，不要加多余空格。

| 配置项                    | 用途                      |
| ---------------------- | ----------------------- |
| `VOLC_APP_ID`          | 火山引擎语音识别 APP ID         |
| `VOLC_ACCESS_KEY`      | 火山引擎语音识别 Access Token   |
| `DEEPSEEK_API_KEY`     | DeepSeek 英文翻译           |
| `BAIDU_TTS_API_KEY`    | 百度智能语音 TTS 的 API Key    |
| `BAIDU_TTS_SECRET_KEY` | 百度智能语音 TTS 的 Secret Key |

注意：百度 TTS 凭证来自百度智能云语音服务，不是百度翻译凭证，也不是 DeepSeek 密钥。

当前程序使用火山引擎豆包流式语音识别 2.0 小时版资源：

```text
volc.seedasr.sauc.duration
```

账号需要具备相应接口、流式识别和说话人分离能力的使用权限。

系统环境变量优先于 `.env`。请勿分享、提交或公开包含真实密钥的 `.env` 文件；已经泄露的凭证应及时轮换。

## 音频路由

识别电脑正在播放的英文时，推荐使用 VB-CABLE：

1. 安装并启用虚拟声卡。
2. 将需要播放的视频、会议或播客输出到 `CABLE Input`。python的输入改为CABLE。
3. 程序会优先查找名为 `CABLE Output` 的录音设备。
4. 如果没有找到 `CABLE Output`，程序会使用系统默认输入设备。

音频要求为 **16 kHz、单声道、16-bit PCM**。如果完全识别不到内容，首先检查虚拟声卡路由和系统默认录音设备。

## 启动程序

在程序所在目录运行：

```bash
python 流式语音识别.py
```

正常使用时，请完整配置火山、DeepSeek 和百度 TTS 凭证。

### 只测试识别

```bash
python 流式语音识别.py --no-translate
```

此模式只需要火山凭证，不调用 DeepSeek 和百度 TTS。

### 识别并翻译，但不播报

```bash
python 流式语音识别.py --no-tts
```

此模式需要火山和 DeepSeek 凭证，不需要百度 TTS 凭证。

### 使用原命令行模式

```bash
python 流式语音识别.py --cli
```

## 悬浮面板使用

### 开始与停止

- 点击 **开始转写翻译**，启动音频采集、识别、翻译和播报。
- 点击 **停止转写翻译**，停止采集并等待尾部识别结果。
- 关闭窗口时，程序也会停止后台任务。

### 对话显示

每组对话按以下结构显示：

```text
说话人 1 · 时间
English sentence
对应的中文译文
```

火山内部说话人编号从 0 开始，面板显示时转换为从 1 开始：

| 火山原始编号 | 面板显示  |
| ------ | ----- |
| 0      | 说话人 1 |
| 1      | 说话人 2 |
| 2      | 说话人 3 |

不同说话人使用不同颜色。即使译文乱序返回，也会插回对应英文下方。

底部的“正在识别”区域显示暂存文字；暂存文字只用于预览，定稿后才进入翻译。

### 隐藏与恢复

- 点击 **隐藏悬浮窗** 或按 `Esc`，窗口会最小化到任务栏。
- 隐藏不会停止后台识别、翻译和播报。
- 点击任务栏中的程序图标即可恢复。
- 取消 **窗口置顶** 后，其他窗口可以覆盖面板。
- 点击 **清空对话** 只清空显示内容，不会停止识别；清空后到达的旧译文不会重新出现。

## 说话人模式

面板右上角提供两种模式：

| 模式   | 判停参数              | 特点                        |
| ---- | ----------------- | ------------------------- |
| 速度优先 | `800ms / 1000ms`  | 默认模式，保持原来的响应速度            |
| 长句优先 | `1400ms / 1500ms` | 等待更长分句，可能改善部分说话人拆分，但会增加延迟 |

默认始终为 **速度优先**。只有手动选择“长句优先”并重新启动转写后，较长分句参数才会生效。

说话人分离不等于真实身份识别。短于 1 秒的有效语音、音色相近、多人重叠说话和音频质量较差，都可能导致同一人被拆分或不同人被合并。长句模式不能保证解决所有情况。

## 常用命令行参数

```text
--cli                     不打开面板，使用命令行模式
--no-tts                  不合成和播放语音
--no-translate            只识别，不翻译、不播报
--no-partial              不显示暂存识别文字
--speaker-mode fast       速度优先，默认值
--speaker-mode long       长句优先，可能增加延迟
--translate-workers 2     翻译线程数，默认 2
--tts-workers 2           TTS 合成线程数，默认 2
```

例如，只使用命令行识别：

```bash
python 流式语音识别.py --cli --no-translate
```

手动启用长句模式：

```bash
python 流式语音识别.py --speaker-mode long
```

## 工作流程

```text
CABLE Output／默认输入设备
        ↓
200ms PCM 音频块
        ↓
火山双向流式识别
        ├─ 暂存文字：只在面板预览
        └─ 定稿文字：进入翻译
                ↓
        DeepSeek 英译中
                ↓
        面板插入对应英文下方
                ↓
        百度多音色 TTS
                ↓
        按原文顺序播放
```

翻译和 TTS 可以并行处理多个任务，但不会为了追赶进度而主动删除旧句。如果上游持续快于下游，可能出现播报滞后；可谨慎增加工作线程，同时注意云服务的并发和限流。

## 常见问题

### 启动时提示缺少环境变量

检查：

1. `.env` 是否与主程序位于同一目录。
2. 文件名是否确实是 `.env`，而不是 `.env.txt`。
3. 配置项名称是否拼写正确。
4. 等号右侧是否已经填写凭证。
5. 修改 `.env` 后是否重新启动程序。

### 完全识别不到文字

按以下顺序排查：

1. 先使用 `--no-translate`，排除翻译和 TTS 环节。
2. 确认 `CABLE Output` 或默认录音设备确实有音频输入。
3. 检查火山 APP ID、Access Token 和服务权限。
4. 查看终端中的连接、重连和错误日志。

### 有英文，没有中文

- 检查 `DEEPSEEK_API_KEY`。
- 检查 DeepSeek 账户额度、网络连接和接口限流。
- 确认没有使用 `--no-translate`。
- 查看终端是否出现“DeepSeek 失败”或“翻译失败”。

### 有译文，没有声音

- 检查两个百度 TTS 凭证。
- 确认没有使用 `--no-tts`。
- 检查系统播放设备和音量。
- 查看终端是否出现 TTS 合成或播放失败。

### 说话人仍然不准确

- 保持默认“速度优先”时，不会牺牲速度换取分离效果。
- 可手动尝试“长句优先”，但应接受更高延迟。
- 尽量避免多人同时说话。
- 检查输入音频是否过小、失真或混有过多噪声。

### 面板隐藏后找不到

在 Windows 任务栏找到“实时转写翻译”窗口图标并点击。隐藏只是最小化，不会退出程序。

## 安全提醒

- 不要把真实密钥写入源代码或公开仓库。
- 不要上传包含凭证的 `.env`。
- 定期检查云服务的调用量和额度。
- 如果源代码或配置文件曾经公开，建议立即轮换相关密钥。
